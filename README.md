# Dungeon-Platfomer
## A platformer game take place in a dungeon, jumps around platform and dodge spikes to reach the end. Will you escape or get trapped forever? 

Making this game was a load of fun! As a beginner myself, this has improve my skill for game development. Created mainly in GoDot.

AI was only used to fix bugs in the game, no content in the game is made with AI.

### Features
- 5 levels to explore
- moving and double-jumps
- spikes and enemys
- collectable coins
- main menu and level selection screen
